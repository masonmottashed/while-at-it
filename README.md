# WhileAtIt

WhileAtIt helps you choose the best open task for the time you have available.

## Files

- `index.html` — app structure and visible text
- `styles.css` — design and layout
- `app.js` — app behavior and local task storage

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select the `main` branch and `/(root)` folder, then save.

The app stores tasks locally in the user's browser. No account or server is required for this version.
